## Pricing Rules

- "5 litres" on the current site becomes "Quarter cooler / 6 litres".
- Half cooler / 12 litres = quarter cooler x 2.
- Full cooler / 24 litres = quarter cooler x 4.
- Takeaway is its own option, not added mathematically to cooler prices.
- Pastries except Puff Puff are sold each only, so no size dropdown.
- Chin Chin is sold per pack only, so no size dropdown.
- Turkey has no takeaway option; show cooler sizes only.
- Fufu follows Eba pricing.
- Mackerel Fish follows Fried Fish pricing.
- Catfish Pepper Soup follows Goat Meat Assorted Pepper Soup pricing.

Use this as the working truth table for the size dropdown. Only show dropdowns where more than one confirmed option exists.
